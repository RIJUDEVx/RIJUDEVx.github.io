## Why it exists

Deploying Salesforce CPQ setups was manual. Migrata turned it into a repeatable, validated pipeline that works across multiple orgs.

## What I built

I built the platform: an automated, multi-org Salesforce data migration pipeline in Node.js. It is released on Salesforce AppExchange.

## The hard parts

### 1. Many orgs, one pipeline

The same migration has to run against several Salesforce orgs without a separate manual process for each one.

### 2. Validated, not manual

The pipeline checks its own output. The old process depended on a person getting each deployment right by hand.

## What changed

Manual CPQ deployments were replaced with a repeatable pipeline. It is listed on Salesforce AppExchange.
