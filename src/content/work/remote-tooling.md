## Why it exists

Managing field-level security and permission sets across Salesforce orgs through the standard setup screens takes many clicks per change.

## What I built

I built the Angular front ends for managing field-level security and permission sets, plus Node.js and Express backend services and REST APIs behind them.

## What changed

It was my introduction to Salesforce's permission model, which later shaped how I designed access control in Selegic CRM.
